# Gravity Screen Flip

Rotates the whole gameplay view by 180° whenever gravity is reversed and rotates it back when gravity returns to normal. Works for any number of gravity changes in a level, with a smooth eased animation.

- Only affects levels you are playing; menus and the editor are untouched.
- Configurable duration, direction behaviour, edge zoom and HUD handling in the mod settings.

**Note:** the view is rotated, not the controls. See the README for details.
